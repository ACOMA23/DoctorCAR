## التحقق اليدوي (PowerShell من `C:\doccar`)
```powershell
# 1) شاشة البدء ثم النافذة (قاعدة تجريبية مستقلة، لا بياناتك)
.\.venv\Scripts\python.exe -m doctorcar --database data\ux-demo.sqlite3
```
1. تظهر نافذة DoctorCAR المركزية فورًا بخمس مراحل ثم تُغلق وتفتح النافذة الرئيسية (≈2 ث).
2. **مركز المصادر** ← المصدر «محاكاة» ← فعّل «مراقبة AI التجريبية» ← «بدء الجلسة»: يعمل خلال لحظة؛ انتقل إلى **لوحة التحكم** (شارة «يستقبل بيانات») ثم **قراءات الحساسات** (بطاقات حية، ابحث «RPM»).
3. اختر «حقن أعطال محددة» + S01 وابدأ؛ بعد الانتهاء: **سجل الأحداث** ← انقر مرتين على الحدث ← ترى الخط الزمني وشارة «AI (استشاري)» وزري النسخ.

5. لإظهار الحركات يلزم تفعيل «تأثيرات الرسوم المتحركة» في Windows (Settings ← Accessibility ← Visual effects) وإلغاء «تقليل الحركة» في الإعدادات.
