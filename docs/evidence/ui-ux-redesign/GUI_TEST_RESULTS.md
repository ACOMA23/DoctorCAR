# DC-UX-001 — نتائج اختبارات الواجهة والتكامل

البيئة: Windows 11، Python 3.14، PySide6، منصة Qt `windows` (نافذة أصلية) لسكربتات GUI وأوامر pytest بـ`offscreen`. كل التشغيلات على قواعد مؤقتة. الإدخال عبر **QTest على عناصر Qt الحقيقية** (ليس أتمتة UI على مستوى النظام). اللقطات: `QWidget.grab()` أو `PrintWindow` لنافذة التطبيق نفسه — ليست صور تصميم.

## لم يُختبر / حدود صريحة
- **تحجيم Windows الفعلي (125%/150%)**: لم يُغيَّر إعداد النظام؛ اختبرت «حجم العرض» داخل التطبيق ومحاكاة `QT_SCALE_FACTOR`. (قد يكون أحد تشغيلات `pr_gui_ext` جرى على شاشة بتحجيم 125% — الإطار 1550×1056 — دون تحقق.)
- **حركة الواجهة بصريًا**: إعداد Windows لتأثيرات الحركة **معطّل على هذا الجهاز** (`Motion.os_allows()=False`)، فلم تُشاهد الحركات؛ مسار الحركة مُختبر برمجيًا بفرض التفعيل، وإيقافها عند التعطيل مُختبر.
- فشل تحميل ML **native**؛ إدخال النظام الحقيقي (فأرة/لوحة مفاتيح OS)؛ قارئ الشاشة؛ Narrator؛ تعدد الشاشات؛ العتاد/Serial.
- النافذة لم تكن في المقدمة في إحدى جولات `pr_gui_ext` (QA-EXT-002 PARTIAL): الرسم صحيح (PrintWindow ≈ grab) لكن لا يراها مستخدم.
