## قضايا عامة
1. **لا نظام تصميم**: QSS واحد ثابت بألوان hex مكررة، والوضع الداكن يتم بـ«استبدال نصوص» (`str.replace`) فوق QSS الفاتح؛ لا tokens ولا سلّم خطوط ولا مسافات.
2. **لا شاشة تحميل**؛ والعمل الثقيل (استيراد ML) يحدث عند أول «بدء جلسة» بلا أي إشارة.
3. **الإشعارات**: لا نجاح مرئي (تصدير، فحص)، والخطأ سطر أحمر وحيد أسفل الصفحة؛ لا دمج للتكرار.
4. **الحالات الفارغة** غائبة (جداول فارغة).
5. **إمكانية الوصول**: لا أسماء accessible للحقول، لا حلقة تركيز على عناصر القائمة، لا قياس للتباين، لا ضبط لحجم الخط.
6. **الاستجابة للحجم**: صفحات بلا تمرير؛ شريط جانبي ثابت؛ أزرار في صف واحد قد تتجاوز العرض عند الخط الكبير.
7. **نقاط قوة يجب حفظها**: فصل العرض عن الأعمال (MainWindow عرض فقط)، `BackendWorker` وحيد، RTL/LTR، ترجمة العرض فقط، رسائل الخطأ الودية (DC-FIX-001)، وجميع أسماء عناصر الواجهة التي تعتمد عليها 280 اختبارًا وسكربتات QA.
