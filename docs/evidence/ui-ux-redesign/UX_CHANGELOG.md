## تغييرات سلوك مقصودة (ليست عيوبًا)
1. زر «إيقاف وحفظ المتاح» معطّل عندما لا توجد جلسة (كان مفعّلًا دائمًا).
2. تغيير اللغة يعيد رسم التقرير المفتوح **دون** الانتقال لصفحة التقرير (كان يقفز).
3. نموذج AI يُحمَّل ويُتحقق من بصمته أثناء شاشة البدء بدل أول «بدء جلسة»؛ زمن جاهزية النافذة ≈2.2 ث بدل ≈0.9 ث، لكن زمن الضغط على «بدء» حتى التشغيل ≈0.06 ث بدل ≈1.7 ث.
4. رسالة فشل فتح التخزين ودّية دون نص الاستثناء/المسار.
5. محررات الأرقام بأرقام لاتينية في اللغتين.

## ما لم يتغير (بقرار)
Session، EventRecorder، SQLiteRepository، القواعد، ML/XAI/السياسة الاستشارية (`ml_alerts=False`)، النموذج v3، Firmware، Ground Truth، قاعدة بيانات المستخدم. إضافة واحدة فقط على العامل: إشارة عرض `session_stats` (عدد العينات المقبولة/المرفوضة).
